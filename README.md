# YogaFlow Landing Page

A modern, premium one-page yoga teacher training landing page built as a clean static HTML/CSS/JS prototype.

## Run locally

Open `index.html` directly in a browser, or serve the folder with a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — page structure and content
- `styles.css` — visual design, layout, colors, spacing, responsive styling
- `script.js` — countdown timer and FAQ accordion logic

## Notes

This version is a fresh landing page scaffold designed to match the premium wellness aesthetic from the supplied reference. You can swap in the original images, exact copy, and brand assets once they are available in the repo.
